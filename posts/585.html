JVM 调优实战：3个参数配置经验总结

2026-09-22 · 性能

很多性能问题的根源不在代码，而在思路。本文带你建立正确的性能优化思维框架。

核心要点

本文将从以下 3 个方面展开，带你系统掌握相关知识：

1. 倒排索引与分词器优化

倒排索引是 ES 高效检索的核心。合理配置分词器能显著提升中文检索准确率，建议对中文文本使用 IK 分词器。

PUT /my_index
{
  "settings": {
    "analysis": {
      "analyzer": {"chinese": {"tokenizer": "ik_max_word"}}
    }
  }
}

2. 聚合查询性能调优

使用 doc_values 替代 fielddata 避免内存溢出，高基数字段慎用 terms 聚合，合理设置 size 限制。

GET /logs/_search
{
  "size": 0,
  "aggs": {"by_status": {"terms": {"field": "status.keyword", "size": 10}}}
}

3. 分片与副本策略

单分片不宜超过 50GB，副本数根据查询压力调整，写入密集型场景可临时关闭副本加速。

PUT /my_index/_settings
{ "number_of_replicas": 0 }

总结

本文从 3 个方面系统介绍了的核心知识。掌握这些内容后，你应该能够在实际项目中灵活运用。建议结合具体场景多练习，加深理解和记忆。
