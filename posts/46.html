curl 高级用法：3个场景掌握 HTTP 调试

2026-09-20 · 工具

工欲善其事，必先利其器。这篇文章将带你重新认识日常工具的高级用法，让你的工作效率再上一个台阶。

核心要点

本文将从以下 3 个方面展开，带你系统掌握相关知识：

  1. 别名配置：让长命令一键触发
  2. 变基整理：让提交历史清晰可读
  3. 全局忽略文件：避免临时文件污染仓库

1. 别名配置：让长命令一键触发

通过别名机制，将常用的长命令简化为几个字符。不仅节省输入时间，还能减少拼写错误。

alias gs='git status'
alias gc='git commit -m'
alias gp='git push origin HEAD'
alias gl='git log --oneline --graph -20'

2. 变基整理：让提交历史清晰可读

交互式变基可以合并提交、调整顺序、修改提交信息，让分支历史像精心编排的故事线。

git rebase -i HEAD~5

# 常用指令:
# p = pick (保留)
# s = squash (合并到上一个)
# r = reword (修改信息)
# f = fixup (丢弃信息)

3. 全局忽略文件：避免临时文件污染仓库

每个开发者的本地环境不同，会产生各种临时文件。全局gitignore让你不用在每个仓库都重复配置。

git config --global core.excludesfile ~/.gitignore_global

# .gitignore_global
.DS_Store
*.swp
*.swo
.idea/
.vscode/
*.local
